# SGM – Frontend

Frontend desarrollado con Vue.js para un Sistema de Gestión de Mantenimiento, orientado a la administración de equipos, sus hojas de vida y el seguimiento de las actividades de mantenimiento.

La interfaz permite consultar y gestionar la información técnica e histórica de los equipos.

## Funcionalidades principales

- Interfaz para el registro y administración de equipos.
- Consulta y gestión de hojas de vida.
- Visualización de información técnica.
- Consulta de trazabilidad de los equipos.
- Registro y consulta de actividades de mantenimiento.
- Visualización del historial de mantenimientos.

## Tecnologías utilizadas

- **Framework:** Vue.js 2.
- **Navegación:** Vue Router.
- **Gestión del estado:** Vuex.
- **Consumo de API REST:** Axios.
- **Notificaciones:** Toastr.
- **Manejo de fechas:** Moment.js.
- **Captura de firmas:** Vue Signature.
- **Visualización de galerías:** Vue Gallery Slideshow.

## Arquitectura

Este repositorio contiene la interfaz de usuario de SGM, desarrollada como una aplicación web que consume los servicios expuestos por el backend mediante una API REST.

## Backend

El servidor está desarrollado con Laravel 8 y MySQL.

[SGM-server – Repositorio backend](https://github.com/jorgepbarrera38/SGM-server)

Software desarrollado integralmente, incluyendo backend y frontend, que fue comercializado mediante membresías y distribuido para instalación local en los equipos de los clientes.
